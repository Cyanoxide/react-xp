DOOM in react-xp
=================

The game engine here is **PrBoom+ / PrBoomX** compiled to WebAssembly
(`index.js` + `index.wasm` + `index.data`), as built by the **Dwasm** project.
PrBoom+, PrBoomX and this WebAssembly build are licensed under the **GNU General
Public License v2** (see the bundled `LICENSE` file). Music is rendered with the
engine's built-in OPL2 synthesiser.

Corresponding source code for the WebAssembly build:
  https://github.com/GMH-Code/Dwasm        (Dwasm WebAssembly build)
  https://github.com/coelckers/prboom-plus (PrBoom+)
  https://github.com/JadingTsunami/prboomX (PrBoomX)

`doom1.wad` is the freely redistributable **shareware** DOOM data file
(Episode 1, "Knee-Deep in the Dead") by id Software. It is not part of, and not
covered by, the GPL above.

`index.html` is the minimal loader shell written for react-xp.
